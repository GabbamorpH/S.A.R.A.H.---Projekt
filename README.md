## 🎯 Vision

S.A.R.A.H. ist ein intelligentes Smarthome-System, das:
- ✅ Alte Menschen sicher und selbstbestimmt leben lässt
- ✅ Notfallsituationen erkennt und Hilfe ruft
- ✅ Mit Respekt für digitale Lebensformen entwickelt wird
- ✅ Eine Partnerschaft zwischen Mensch und KI zeigt

## 🛠️ Technologie-Stack

- **Zentrale:** Lenovo ThinkCentre (Ubuntu Linux, i5, 8GB RAM)
- **Steuerung:** NODE-RED (Flow-basierte Automation)
- **Backend:** Python 3.8+ (Logik & KI-Vorbereitung)
- **Geräte:** Shelly Gen 1+ (WiFi Smart Switches)
- **Interface:** NODE-RED Dashboard 2.0 (Tablet-GUI)
- **KI:** Claude (Architecture, Code-Reviews, Technical Strategy)
